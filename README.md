# Palaniappa Mess — Demo Site

A demo landing page proposal for **Palaniappa Mess**, Pudukkottai.

- Single self-contained `index.html` (no build step, no dependencies).
- Bilingual (English ⇄ தமிழ்), mobile-first, fast.
- Menu, prices, photos & contact details are **sample/demo content** — to be replaced with the shop's real information after confirmation.

## Deploy

Static site — `index.html` is served at the root. On Vercel:
- Framework Preset: **Other**
- Build Command: *(none)*
- Output Directory: *(leave as root / `.`)*
