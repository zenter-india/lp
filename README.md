# Aiswaryaa Hotel — Demo Site (branch: aiswaryaa)

A demo landing page proposal for **Aiswaryaa Hotel**, Pudukkottai (pure-veg tiffin & meals).

- Single self-contained `index.html` (no build step, no dependencies).
- Bilingual (English ⇄ தமிழ்), mobile-first, fast.
- **"Banana Leaf Editorial"** design — deliberately distinct from other client sites.
- Menu, prices, photos & contact details are **sample/demo content** — to be replaced with the shop's real information after confirmation.

> Each client lives on its own branch of this repo (e.g. `main` = Palaniappa Mess, `aiswaryaa` = Aiswaryaa Hotel), so Cloudflare Pages gives each a separate preview URL.

## Deploy

Static site — `index.html` served at the root. On Cloudflare Pages: no build command, output directory `.`
